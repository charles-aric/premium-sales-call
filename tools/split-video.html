Split video into parts

This runs on your computer only. Nothing gets uploaded from this page. It cuts the video into 20 MB files that Cloudflare Pages and GitHub both accept, and writes a small manifest file that tells the site how to put them back together.

After the downloads finish
  1. Your browser may ask to allow multiple downloads. Allow it.
  2. Upload every .bin file to the public/vparts folder of the GitHub repo.
  3. Upload video-manifest.js to the lib folder of the repo, replacing the one that is there.
  4. Cloudflare redeploys on its own after each commit.
